# Custom Cursor Extension

Welcome to the **Custom Cursor Extension**! This extension is a collection of animated and static custom cursors designed to enhance your web browsing experience. The extension provides various themes such as electric, fire, galaxy, and more to customize your cursor style.

## Features
- **Custom Cursors**: A variety of cursors with unique designs.
- **Animated Cursors**: Dynamic cursors that animate for a fun browsing experience.
- **Easy Installation**: Simple steps to install and change your cursor on Chrome.
- **Free & Open Source**: All files are open for you to download, modify, or contribute.

## Available Themes
- **Electric Cursors**: A set of electrifying animated and static cursors.
- **Fire Cursors**: Fiery themed cursors to light up your screen.
- **Galaxy Cursors**: Space-inspired cursors for a cosmic experience.

## Installation Instructions

1. **Go to the Chrome Web Store**: [Link to your Extension on Chrome Web Store].
2. **Click "Add to Chrome"**: Once the extension page is open, click the "Add to Chrome" button.
3. **Confirm**: Click "Add Extension" to confirm the installation.

## How to Use
- Once installed, click the extension icon in the Chrome toolbar.
- Browse through available cursor themes and choose your desired design.
- Apply the cursor, and it will be activated immediately on your browser!
